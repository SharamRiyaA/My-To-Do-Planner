# My To-Do Planner

**My To-Do Planner** is a simple and intuitive web application designed to help you manage your daily tasks efficiently. With this app, you can add, track, complete, and review your tasks all in one place.

## Features

### Add Task
- Create new tasks with a title, date, and time.  
- Plan your day effectively and stay organized.

### View Task
- See all your active tasks in a clean interface.  
- Mark tasks as completed once done.  
- Delete tasks you no longer need.

### Completed Task
- Review all completed tasks.  
- Track your productivity and accomplishments.

## How It Works
1. Go to the **Add Task** page to create a new task with a title, date, and time.  
2. Navigate to **View Task** to see all active tasks. Mark tasks as completed or delete them if needed.  
3. Visit the **Completed Task** page to view all tasks you’ve completed.

## Tech Stack

**Frontend:**  
- HTML / CSS / JavaScript  
- React.js (for SPA and component-based UI)  

**Backend:**  
- Node.js with Express.js  

**Database:**  
- MongoDB (NoSQL, flexible and easy to use with JavaScript)
